# Kenya Retail Sales Analysis

## Project Overview

This portfolio project illustrates practical ‘Junior Data Analyst’ skills in the analysis of a sample of retail sales data for six months.

Please note that the data set is artificial and is being used for portfolio/demo purposes only. It is not a genuine organisation.

## Business Questions

Which are the most profitable and most revenue bringing products?
What is the trend of the revenue?
What are the best sales channels?
* What actions could management take from the results?

## Tools

* Python
* Pandas
* Matplotlib
* CSV
* GitHub

## Analysis Workflow

Imported the transaction data using Pandas.
2. Developed a month time field.
3. Revenue, profit, units sold, average transaction value and profit margin calculated.
Analysed achieved by product, month and sales channel.
5. Exported summary tables.
6. Made visualizations to tell what they found.

## Key Findings

It is analyzed to identify top performing products, monthly revenue trends, channel performance and profitability opportunities.

A Python script is included that can run the analysis from the dataset.

## Recommendations

When planning stock, prioritize products that have a high revenue and high margin.
Analyze discounts for profitability which do not support the volume advantage gained.
Perform a comparison of sales channels, based on profit, as well as revenue.
Monitor revenue and profit together to assess business performance.

## How to Run

Install the following libraries:

```bash
pip install -r requirements.txt
```

Then run:

```bash
python analysis/analyze_sales.py
```
